# UserOrient Feedback

Raw feedback transcribed from the screenshots.

## Reduced Feature Wishes

1. **Randomized item pool for boards**
   Let creators enter more items than the board needs, then randomly fill each new board/play from that larger pool.

2. **Bulk paste/import of square text**
   Allow users to paste a list of items and have the app distribute them into board squares automatically.

3. **Shuffle board contents**
   Randomize the order of entered board items.

4. **Locked free space**
   Support a center/free square that stays fixed when the board is shuffled.

5. **Unique shuffled boards for each participant**
   When sharing or starting a group game, automatically generate a different shuffled board for each player.

6. **Collaborative item contribution before play**
   Let invited members contribute square text before each player receives their own generated board.

7. **Live shared bingo play**
   Let multiple people play the same bingo game together interactively.

8. **Competition mode**
   Add multiplayer scoring or race conditions such as first to finish or most points.

9. **iMessage group chat play**
   Add an iMessage/group chat option for real-time play.

10. **Shareable interactive board**
    Make boards shareable as an interactive experience rather than only static content.

11. **Duplicate board**
    Let users duplicate an existing bingo board.

12. **Adjust board size after starting**
    Allow changing the board dimensions after a game/board has already been created.

13. **Dark mode**
    Add a dark theme for lower-brightness use.

14. **More playful visual styling**
    Make the app look more colorful, fun, cool, and distinctive.

15. **Customization and premium extras**
    Offer additional customization or extra features, potentially as a one-time paid upgrade.

16. **Long-text handling per square**
    Let users adjust text size per box, or otherwise support longer square text cleanly.

17. **Add images to boards or squares**
    Support images/photos as board or square content.

18. **Photo reveal on square completion**
    When a square is completed, display a random photo from a user-provided collection.
